# UI/UX & Design Guidelines

This project uses a design system inspired by **Odoo**'s clean, ERP-like business interface.

## Design Tokens

- **Primary Color**: Odoo Purple (#714B67 or #71639e)
- **Secondary Color**: Slate / Gray neutrals
- **Success**: Emerald green
- **Danger**: Red / Crimson
- **Font Family**: Modern sans-serif (e.g., Inter, Outfit, or standard system-ui)

## Key Layout Patterns

- **Sidebar**: Standard navigation menu
- **Topbar**: User profiles, breadcrumbs, and search
- **Dashboard Cards**: Key metrics at a glance
- **Data Tables**: Clean, paginated lists with filtering and actions

## Visual Theme & Atmosphere
- Light background, strong purple brand accent color.
- Moderate density, friendly but professional ERP dashboard look.
